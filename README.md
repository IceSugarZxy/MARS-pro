# MARS Pro

MARS Pro 是基于 PyQt5 的旋转体表磁测量分析系统，适配 **3Axis_MARS v1.x 固件**（USB CDC 虚拟串口），支持 X/Y/Z 三轴滑台 + R 轴卡盘旋转电机的四轴控制。

当前仓库根目录就是 MARS pro/ 本身。

> MARS Pro 是从 [MARS](https://github.com/IceSugarZxy/MARS)（V3.5 固件）升级而来，通信协议、硬件架构、控制方式均有重大变化。

## 2026-10-08 更新要点

1. **采集档位统一走参数接口**：删除固件 `MODE<n>~` 指令，三档全部改用 `ACQCFG` + `ADCRATE`
   参数下发（参数见「采集档位」一节）；切换档位按下发顺序 `ACQCFG → ADCRATE → PGA → IDAC`
   执行，每次改档都重发上位机当前选定的 PGA/IDAC 组合，避免固件残留档位覆盖上位机设置。
2. **偏置校准改用 `H~` 连续 Hall 流**：一轮固定 5 s，取中间 3 s 稳定段求均值；校准期间暂停
   位置查询，避免回信混入偏置数据流；进度条按 5 s 窗口推进。
3. **首数据等待不再轮询 `M~`**：改回普通超时机制（启动 30 s / 中断 2 s），避免 `M~` 回信
   与二进制测量流互相干扰。
4. **文档与交付物**：`用户手册.md` 按当前界面与流程重写；新增 `USB_CDC_通信协议手册.md`
   （替代并删除 `软件通信手册.md`）；新增 A4 单页操作指南与完整使用手册（位于工作区
   `产品介绍与使用说明/`，不在本仓库内）。

## 2026-09-30 更新要点

1. **同轴度（偏心）修正固定启用**：删除界面开关，数据处理始终剥离“一圈一次”偏心分量，
   角度域修过零点/极间隔、幅值域修 N/S 极值；波形不做角度重采样，THD/面积保持原始口径。
2. **修复闭合点裁切错误**（间隔误差虚高的主因）：过去在 ±1/4 磁周期内找闭合点，
   会锁到峰值平台上的错误位置、裁掉一整段数据仍按 360° 映射，收尾间隔被算短
   （实测一轮把 36.1° 算成 28.4°，S间隔误差 2.66% 虚高到 11.01%）。现限制裁切量 ≤0.2%
   并加评分上限，超限不裁切。
3. **削顶自动检测与降档重测**：按顶轨点占比反推真实峰值后自动换档重测一次。
4. **默认参数**：测试速度默认“均衡”；量程默认最大档 ×1，且连接后由上位机下发档位。
5. **缺陷指纹旋转分析工具**：验证幅值/间隔两类缺陷图像同步随样品旋转，产出可视化报告。

详细条目见文末“近期调整”。

## 功能概览

- 串口连接、自动扫描串口和启动时自动连接
- X/Y/Z 三轴滑台实时位置查询（M~ 命令，1.5s 轮询）
- 运动命令自动绝对->相对换算（X+5000~ / Z-3000~），START 确认 + DONE 信号等待，位置追踪智能超时（堵转检测）
- B~ 采集两段超时（启动 30s / 中断 2s）自动结束；等待首数据期间不轮询 `M~`，`_measurement_active` 标志隔离文本解析器与二进制数据流
- 采集速度三档（高精度 / 均衡 / 高速，默认**均衡**）：改用 `ACQCFG`+`ADCRATE` 参数指令（不再发 `MODE<n>~`，参数见「采集档位」），切换档位按 `ACQCFG → ADCRATE → PGA → IDAC` 顺序下发且重发当前 PGA/IDAC 组合，B~ 发送前 flush_write_queue 同步刷新写队列确保指令实际发出
- 旋转测量全部原始数据 0-360° 线性绘制，波形分析保留、失败显示 `--`
- 测量完成对话框常驻，用户手动确认关闭
- 测试位置 / 挂起位置保存、移动和流程化执行
- 偏置校准改用 `H~` 连续 Hall 流（一轮固定 5 s，取中间 3 s 稳定段均值，校准期间暂停位置查询）、零位校准（三轴归零 I~）
- 测试配置面板“全量程偏置校准”：一键顺序校准 8 个量程，表格实时显示各量程偏置，可立即取消
- 平面旋转、外侧面旋转、内侧面旋转、外侧面垂直四种测试类型
- 可编辑的测试 / 挂起移动方案，测量界面与配置面板同步显示当前流程
- 测试模式支持 X / Z 偏移量配置
- 实时波形显示、双击恢复默认坐标、历史波形蓝色显示
- N/S 极峰值、极间隔、面积、THD、极对数等结果分析，并支持极值、过零点和周期误差明细查看
- **同轴度（偏心）修正固定启用**：自动剥离夹具偏心带来的“一圈一次”分量（角度域修正过零点/极间隔，幅值域修正 N/S 极值），波形本身不做重采样，THD/面积保持原始口径
- **削顶（ADC 顶轨）自动检测**：顶轨点占比 ≥0.05% 即告警，并按顶轨占比反推真实峰值自动降档重测一次
- **量程默认最大档 ×1**；串口连接后由上位机把量程档位下发给固件，避免被固件上一次残留的窄档覆盖
- 历史数据自动刷新、筛选和双击加载
- 双文件波形比对和结果比对
- QPainter 三角箭头的台控面板（配置面板 60×60、测量面板 50×50，按住发送 ±25000 步相对移动，松开 O~ 急停）
- PyInstaller 打包，使用 src/icon.png 生成的图标

## 与 MARS（旧版）的主要差异

| 项目 | MARS (V3.5) | MARS Pro (v1.x) |
|------|-------------|-----------------|
| 滑台轴 | X/Z 双轴 | **X/Y/Z 三轴** |
| 旋转轴 | 直流有刷电机+编码器 | **R 轴步进电机（卡盘）** |
| 运动命令 | `X5000~`（绝对） | `X+1000~`（带符号相对） |
| 运动等待 | 轮询 ?XZ 比对位置 | **监听 DONE 信号** |
| 位置查询 | `?XZ~` -> `X:5000,Z:3000` | **`M~` -> 多行全状态** |
| 贴靠 | P~/Y~ 自检 | **已移除**（硬件光电保护） |
| 偏置校准 | K~ 定时采集 | **H~ 连续流 5 s，取中间 3 s 均值** |
| 采集 | B{pulse}~ | **B~（无参数）** |
| 采集档位 | 固定 | **高精度/均衡/高速 三档可选（ACQCFG + ADCRATE）** |
| ADC | ADS8691 | ADS1261(Hall) + ADS8691(Curr) |
| 存储 | MRAM | 无板载存储 |

## 环境要求

- Windows 10/11
- Python 3.8+
- 3Axis_MARS v1.x 固件硬件

安装依赖：

```powershell
pip install -r requirements.txt
```

## 启动

源码运行：

```powershell
python src/main.py
```

打包后运行：

```powershell
dist/MARS_Pro/MARS_Pro.exe
```

## 打包

打包成 **onedir 文件夹**（`dist/MARS_Pro/`，含 `MARS_Pro.exe`）：

```powershell
pip install pyinstaller
pyinstaller MARS.spec --clean --noconfirm
```

### 随包附带的历史波形数据

`MARS.spec` 会把 `data/plot_data/<日期>/` 打进 `dist/MARS_Pro/data/plot_data/<日期>/`，
运行时“历史数据”面板可直接加载。默认打**今天**，可用环境变量指定：

```powershell
set MARS_BUNDLE_DATA=20260930,20260729   &rem 多个日期用逗号分隔
set MARS_BUNDLE_DATA=none                &rem 不带任何历史数据
pyinstaller MARS.spec --clean --noconfirm
```

### ⚠ 必须在纯 ASCII 路径下构建

PyQt5 自带的 Qt 5.15 在**安装路径含中文**时，`QLibraryInfo` 返回的插件路径会被破坏
（`旋转体表磁测量分析系统` → `???????????`），PyInstaller 的 Qt hook 检查该路径时会直接报
`Qt plugin directory ... does not exist!`。**工程目录本身可以含中文，但构建用的 Python
环境不能。** 做法：把 `.venv` 复制到 ASCII 路径（如 `C:\mars_build\`），用复制后的解释器构建：

```powershell
robocopy ".venv" "C:\mars_build\.venv" /E /XD __pycache__ /NFL /NDL /NJH /NJS
robocopy "." "C:\mars_build" src data\plot_data\20260930 logs 一致性测试 MARS.spec /E
cd C:\mars_build
C:\mars_build\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm MARS.spec
```

构建产物可正常从中文路径运行（Qt 运行时按 DLL 所在目录找插件，不受该问题影响），
把 `C:\mars_build\dist\MARS_Pro\` 拷回任意位置即可。

## 采集档位（ACQCFG / ADCRATE）

三档采集参数只通过参数接口下发，不再使用固件封装的 `MODE<n>~`：

| 测试速度 | ACQCFG | ADCRATE | 每圈点数 |
|---|---|---|---|
| 高精度（0） | `ACQCFG50,260,1,4~` | `ADCRATE2400~` | 131072 |
| 均衡（1，默认） | `ACQCFG200,579,2,4~` | `ADCRATE7200~` | 65536 |
| 高速（2） | `ACQCFG200,879,4,4~` | `ADCRATE4800~` | 32768 |

`ACQCFG` 四个参数依次为**起始转速、目标转速、分频、每圈边沿数**。切换档位时按下发顺序
`ACQCFG → ADCRATE → PGA → IDAC` 执行；每次改档都会重发上位机当前选定的 PGA/IDAC 组合，
避免固件里上一次残留的档位覆盖上位机设置。

对应实现：`src/core/serial_command.py`（`TEST_SPEED_TO_COMMANDS`）、
`src/core/data_process.py`（`SAMPLES_PER_REV`）。

## 配置说明

- 源码运行读取 `src/configuration.txt`
- 打包运行读取 exe 同级目录的 `configuration.txt`（即 `dist/MARS_Pro/configuration.txt`）
- 如果配置文件不存在，程序会按默认值自动创建

常用字段：

```text
offset:198.5
COM:COM3
idac_index:4                 # IDAC 电流档位 3~6（3=500μA 档 … 6=1500μA 档，界面只显示挡位）
pga_gain:0                   # PGA 档位 0~7 = ×1~×128（默认 0=×1，量程最大）
range_estimate_mt:120        # 量程估计值（mT），测量/配置界面共用；选档目标 = 该值 + 10mT
pga_offsets:{...}            # 一维偏置表（按 PGA，兼容旧版）
pga_idac_offsets:{"5:4": -10622.3}   # 二维偏置表，键 "PGA:IDAC"，由全档偏置校准写入
test_x:466101
test_z:621952
suspend_x:541107
suspend_z:585155
test_type:0
test_speed:1                 # 0=高精度 / 1=均衡 / 2=高速（默认 1=均衡）
inner_x_offset:5.0
inner_z_offset:5.0
```

选档规则：目标 = 估计值 + 10 mT，在 IDAC3~6 × PGA×1~×128 中取“量程 ≥ 目标且量程最小”的组合
（并列优先电流更大者）；组合量程 = (32768 − |该组合零场偏置|) ÷ 该档换算系数 ÷ 该档电流比例。

X / Y / Z 轴位移与脉冲换算系数：

- X 轴：`640.53` 脉冲 / mm（100000 脉冲 = 156.12 mm）
- Y 轴：`640.53` 脉冲 / mm（与 X 轴统一标定）
- Z 轴：`800.98` 脉冲 / mm（2026-09-07 修正：前后滑台为不同型号，原 6407.80 使 5 mm 指令实际走 40 mm，÷8）
