# MARS Pro

MARS Pro 是基于 PyQt5 的旋转体表磁测量分析系统，适配 **3Axis_MARS v1.x 固件**（USB CDC 虚拟串口），支持 X/Y/Z 三轴滑台 + R 轴卡盘旋转电机的四轴控制。

当前仓库根目录就是 MARS pro/ 本身。

> MARS Pro 是从 [MARS](https://github.com/IceSugarZxy/MARS)（V3.5 固件）升级而来，通信协议、硬件架构、控制方式均有重大变化。

## 功能概览

- 串口连接、自动扫描串口和启动时自动连接
- X/Y/Z 三轴滑台实时位置查询（M~ 命令，1.5s 轮询）
- 运动命令自动绝对->相对换算（X+5000~ / Z-3000~），START 确认 + DONE 信号等待，位置追踪智能超时（堵转检测）
- B~ 采集两段超时（启动 2s / 中断 2s）自动结束，`_measurement_active` 标志隔离文本解析器与二进制数据流
- 采集模式三档切换：MODE0/1/2，切换即时发送指令，B~ 前 300ms 延迟 + 双清队列确保切换生效
- 旋转测量全部原始数据 0-360° 线性绘制，波形分析保留、失败显示 `--`
- 测量完成对话框常驻，用户手动确认关闭
- 测试位置 / 挂起位置保存、移动和流程化执行
- 偏置校准（B~ 一圈采集，取平均值）、零位校准（三轴归零 I~）
- 平面旋转、外侧面旋转、内侧面旋转、外侧面垂直四种测试类型
- 可编辑的测试 / 挂起移动方案，测量界面与配置面板同步显示当前流程
- 测试模式支持 X / Z 偏移量配置
- 实时波形显示、双击恢复默认坐标、历史波形蓝色显示
- N/S 极峰值、极间隔、面积、THD、极对数等结果分析，并支持极值、过零点和周期误差明细查看
- 可选保存原始测量数据
- 历史数据自动刷新、筛选和双击加载
- 双文件波形比对和结果比对
- QPainter 三角箭头的台控面板（配置面板 60×60、测量面板 50×50，按住发送 ±25000 步相对移动，松开 O~ 急停）
- PyInstaller 打包，使用 src/icon.png 生成的图标

## 与 MARS（旧版）的主要差异

| 项目 | MARS (V3.5) | MARS Pro (v1.x) |
|------|-------------|-----------------|
| 滑台轴 | X/Z 双轴 | **X/Y/Z 三轴** |
| 旋转轴 | 直流有刷电机+编码器 | **R 轴步进电机（卡盘）** |
| 运动命令 | `X5000~`（绝对） | `X+1000~`（带符号相对） |
| 运动等待 | 轮询 ?XZ 比对位置 | **监听 DONE 信号** |
| 位置查询 | `?XZ~` -> `X:5000,Z:3000` | **`M~` -> 多行全状态** |
| 贴靠 | P~/Y~ 自检 | **已移除**（硬件光电保护） |
| 偏置校准 | K~ 定时采集 | **B~ 一圈取平均** |
| 采集 | B{pulse}~ | **B~（无参数）** |
| 采集模式 | 固定 | **MODE0/1/2 三档可选** |
| ADC | ADS8691 | ADS1261(Hall) + ADS8691(Curr) |
| 存储 | MRAM | 无板载存储 |

## 环境要求

- Windows 10/11
- Python 3.8+
- 3Axis_MARS v1.x 固件硬件

安装依赖：

``powershell
pip install -r requirements.txt
``

## 启动

源码运行：

``powershell
python src/main.py
``

打包后运行：

``powershell
dist/MARS/MARS.exe
``

## 打包

``powershell
pyinstaller MARS.spec --clean --noconfirm
``

## 配置说明

- 源码运行读取 `src/configuration.txt`
- 打包运行读取 `dist/MARS/configuration.txt`
- 如果配置文件不存在，程序会按默认值自动创建

常用字段：

``text
offset:198.5
COM:COM3
test_x:466101
test_z:621952
suspend_x:541107
suspend_z:585155
test_type:0
test_speed:0
sensor_range:0
inner_x_offset:5.0
inner_z_offset:5.0
``

X / Y / Z 轴位移与脉冲换算系数：

- X 轴：`640.53` 脉冲 / mm（100000 脉冲 = 156.12 mm）
- Y 轴：`640.53` 脉冲 / mm（与 X 轴统一标定）
- Z 轴：`6407.80` 脉冲 / mm（保留旧标定）
