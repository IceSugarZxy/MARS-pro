# 一致性测试脚本说明

本目录用于连续采集 `plot_data` 数据，并对多次测量结果做一致性、波动性可视化分析。

## 1. 自动重复测量并保存

脚本：`auto_measure_save.py`

建议先进入 MARS 项目根目录：

```powershell
cd e:\Python_project\旋转体表磁测量分析系统\当前版本\MARS
```

默认运行 20 次测量，每次保存后等待 1 秒：

```powershell
python 一致性测试\auto_measure_save.py
```

常用参数：

- `--count 20`：执行 20 次测量；设为 `0` 表示持续循环
- `--delay 1`：每次保存完成后等待 1 秒再开始下一次
- `--serial-wait 30`：最多等待串口自动连接 30 秒
- `--measure-timeout 180`：单次测量最长等待 180 秒
- `--save-delay 0.5`：收到分析完成信号后等待 0.5 秒再保存
- `--keep-open`：指定次数完成后不自动关闭 MARS 窗口

保存位置：

- 处理后的测量数据会按日期保存到 `data/plot_data/YYYYMMDD/`
- 如测量界面勾选了保存原始数据，原始数据会保存到 `data/raw_data/`

注意事项：

- 脚本会启动正常 MARS 主程序，并复用测量界面的“开始旋转测量”和“保存数据”逻辑
- 运行前请确认串口设备连接正常，MARS 配置文件中的串口参数正确
- 脚本现在位于 `一致性测试` 目录下，已自动定位上一级 MARS 项目根目录

## 2. plot_data 一致性可视化分析

脚本：`plot_data_consistency_viewer.py`

从 MARS 项目根目录运行：

```powershell
python 一致性测试\plot_data_consistency_viewer.py
```

打开窗口后的操作流程：

1. 点击“添加文件”，可一次选择多个 `data/plot_data/YYYYMMDD/*.csv` 文件，文件会先加入左侧列表
2. 用文件前的勾选框选择参与分析的文件，也可以使用“全选”或“全不选”快速调整
3. 点击“开始分析”，程序只读取当前勾选的文件

窗口内容：

- 左侧列表：显示已添加的文件，并控制哪些文件参与分析
- 右侧图表：同时显示极值误差、过零点误差、单极误差、累计误差四条趋势图
- 每张图都会绘制选中文件序列的误差变化，并用红色虚线标出均值线
- 界面不再显示明细数据表，只保留用于判断波动性的图形结果

由于多次测量之间可能存在相位移动，本工具不按具体极值序号、过零区间序号或周期序号做逐点差值比较，只比较每个文件最终计算出的统计量及其跨文件波动。

建议用法：

1. 先使用 `auto_measure_save.py` 连续保存一批 `plot_data` 文件
2. 再用 `plot_data_consistency_viewer.py` 将这些文件加入列表
3. 勾选需要参与本次比较的文件并点击“开始分析”
4. 对比四类误差指标在多次测量中的一致性和波动性
